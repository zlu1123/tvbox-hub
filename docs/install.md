# 电视端安装：四条路，按可行性排序

国内安卓电视装第三方 APK，基本就这四种办法。**优先走第 1 条**，一次配好以后升级都是 `adb install -r` 一句话。

---

## 路线 1：电脑局域网直推（推荐）

前提：电视和电脑连同一个 WiFi，电视开了 ADB 调试。

### 1.1 电视端打开调试开关

各品牌入口名称不一样，找「开发者选项」就对了：

| 品牌 | 开启方式 |
|---|---|
| 小米 / Redmi | 设置 → 关于 → 连点「版本号」7 次 → 开发者选项 → 打开 **USB 调试** + **USB 安装** + **网络调试** |
| 海信 | 设置 → 关于 → 连点「版本号」→ 开发者选项 → **USB 调试** |
| 创维 / 酷开 | 设置 → 关于本机 → 连点「版本号」→ 开发者选项 → **USB 调试** |
| TCL / 雷鸟 | 设置 → 系统 → 关于 → 连点「版本号」→ 开发者选项 |
| 长虹 | 设置 → 关于 → 连点「版本号」→ 开发者选项 |
| 索尼（国行安卓） | 设置 → 系统 → 关于 → 连点「版本号」→ 开发者选项 |

> 小米电视的「USB 安装」不打开，adb install 会报 `INSTALL_FAILED_USER_RESTRICTED`，这是最常见的一个坑。

### 1.2 找电视 IP

设置 → 网络 / 关于本机 → 状态信息 → IP 地址，一般是 `192.168.x.x`。

### 1.3 电脑上执行

```bash
cd tvbox-hub
./scripts/install_tv.sh scan              # 不确定 IP 就先扫一遍
./scripts/install_tv.sh download          # 从官方仓库拉最新 APK 到 apk/
./scripts/install_tv.sh install 192.168.1.23
```

第一次 `adb connect` 时电视上会弹「允许 USB 调试吗」，用遥控器点**允许**（勾上「一律允许」）。

装完会自动启动。之后升级只要重复 `download` + `install`。

## 路线 2：U 盘（最笨但最稳）

适合电视死活开不了调试的情况。

1. 电脑上把 APK 拷到 U 盘根目录，改名成简单的英文，比如 `tvbox.apk`
2. U 盘插电视，打开电视自带的「媒体中心 / 文件管理」
3. 找到 apk → 确定 → 电视会提示「未知来源应用」，去设置里允许
4. 安装完拔掉 U 盘

> 注意：部分电视（尤其海信、创维）自带的文件管理器会**隐藏 apk 文件**，看不到就装个「小白文件管理器」的 TV 版再从里面找。

---

## 路线 3：电视端浏览器 / 当贝市场

1. 电视上装「当贝市场」或「沙发管家」
2. 搜 `TVBox`——**大概率搜不到**，这类市场对第三方播放器审核很严
3. 退而求其次：用电视浏览器访问 APK 的下载直链，下完直接点安装

这条路成功率最低，仅作备选。

---

## 路线 4：手机遥控推送（免 U 盘免电脑）

1. 手机装「甲壳虫 ADB 助手」（Android）或「Apps2Fire」
2. 手机和电视同一 WiFi，输入电视 IP 连接
3. 手机上选本地 APK → 安装到电视

适合家里没电脑的场景。

---

## 装完之后：把源填进去

1. 电视上打开 TVBox
2. 首次启动会要求填「配置地址」，或者在 设置 → 配置地址 里填：

   ```
   https://cdn.jsdelivr.net/gh/zlu1123/tvbox-hub@main/config/index.json
   ```

3. 确定 → 返回首页 → 等它拉取配置（右上角会有进度）
4. 直播入口在首页「直播」或「电视」标签；点播在「点播 / 影视」

> 如果电视提示「配置获取失败」：
> - 先用手机浏览器打开那个地址，能下载到 JSON 就说明地址没问题
> - GitHub Pages 国内偶尔抽风，可以在源地址前加 `https://ghproxy.net/` 之类加速前缀，或者按 README 里的方法换 Gitee 镜像

## 常见报错对照

| 现象 | 原因 | 处理 |
|---|---|---|
| `INSTALL_FAILED_USER_RESTRICTED` | 没开「USB 安装」 | 开发者选项里打开 |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 签名和已装的旧版冲突 | 先 `adb uninstall 包名` 再装 |
| `adb: device offline` | 电视休眠或断网 | 电视唤醒后重新 `adb connect` |
| 找不到设备 | 路由开了 AP 隔离 | 关掉路由器的「AP 隔离 / 访客网络隔离」 |
| 装上了但打不开 | CPU 架构不匹配 | 换 `-java32.apk` 或 `-java64.apk` 再试 |
